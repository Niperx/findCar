# FindCar - Парсер габаритов автомобилей с Drom.ru

Веб-приложение на Flask для поиска габаритов и массы автомобилей с сайта drom.ru.

## Возможности

- Парсинг данных о габаритах автомобилей с drom.ru
- Получение длины, ширины, высоты и массы автомобиля
- Автоматическая классификация по типу кузова на основе габаритов
  - Малолитражка, Городской автомобиль, Кей-Кар
  - Седан, Длинный седан
  - Кросс, Длинный кросс
  - Джип, Длинный джип
  - Большое авто
- Автодополнение марок и моделей
  - База из 20+ популярных марок
  - 200+ популярных моделей
  - Умный поиск при вводе
- Современный интерфейс с анимацией
- Прямая ссылка на источник данных

## Установка и запуск

### Установка через Docker (рекомендуется)

1. Убедитесь, что Docker установлен на вашем компьютере
2. Соберите и запустите контейнер:
```bash
docker-compose up -d
```

Или вручную:
```bash
# Собрать образ
docker build -t findcar .

# Запустить контейнер
docker run -d -p 5000:5000 --name findcar-app findcar
```

Приложение будет доступно по адресу: http://localhost:5000

Остановка контейнера:
```bash
docker-compose down
```

### Автоматическая установка (Windows)

1. Запустите `setup.bat` для создания venv и установки зависимостей
2. Запустите `run.bat` для запуска приложения

### Ручная установка

1. Создайте виртуальное окружение:
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python -m venv venv
source venv/bin/activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Использование

1. Введите марку автомобиля (латиницей, например: Toyota, BMW, Subaru)
2. Введите модель автомобиля (латиницей, например: Camry, X5, Impreza)
3. Нажмите "Найти габариты"
4. Получите данные о длине, ширине, высоте и массе автомобиля

## Примеры

- Subaru Impreza
- Toyota Camry
- BMW X5
- Lada Vesta
