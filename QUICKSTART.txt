🚀 ДЛЯ WINDOWS:

1. Двойной клик по файлу: setup.bat
   (Создаст venv и установит все зависимости)

2. Двойной клик по файлу: run.bat
   (Запустит приложение)

3. Откройте браузер: http://localhost:5000

═══════════════════════════════════════════════════

📝 РУЧНАЯ УСТАНОВКА:

1. Откройте терминал в папке проекта

2. Создайте venv:
   python -m venv venv

3. Активируйте venv:
   Windows:    venv\Scripts\activate
   Linux/Mac:  source venv/bin/activate

4. Установите зависимости:
   pip install -r requirements.txt

5. Запустите:
   python app.py
